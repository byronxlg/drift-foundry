How it plays

  1. You are posted to this ground to mine it. The posting ends at 100%.
  2. Each patch holds a set amount. Drills empty it; empty counts as mined.
  3. Mining pays for machines and opens the next stretch, with more and richer patches.
  4. Hub stock is what you build with, never a score.
